# หาคู่ตีแบด

เว็บหาเพื่อนตีแบดมินตัน รันบนเครื่องตัวเอง ใช้แค่ Node.js ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

## วิธีรัน

```bash
cd badminton
npm start        # หรือ node server.js
```

แล้วเปิด http://localhost:3000

เพื่อนที่ต่อ Wi-Fi เดียวกันเปิดได้จากที่อยู่ที่ขึ้นในเทอร์มินัล (เช่น `http://192.168.1.35:3000`)
เปลี่ยนพอร์ตได้ด้วย `PORT=8080 npm start`

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `server.js` | เซิร์ฟเวอร์ เสิร์ฟหน้าเว็บ + API เก็บข้อมูลลง `data.json` |
| `public/index.html` | โครงหน้าเว็บ |
| `public/style.css` | หน้าตา (รองรับโหมดมืด และมือถือ) |
| `public/app.js` | การทำงานฝั่งเบราว์เซอร์ ดึงข้อมูลใหม่ทุก 5 วินาที |
| `data.json` | ข้อมูลก๊วนและคนเข้าร่วม (สร้างเองตอนรันครั้งแรก พร้อมก๊วนตัวอย่าง) |

ลบ `data.json` แล้วรันใหม่ = เริ่มจากข้อมูลตัวอย่างอีกครั้ง

## API

- `GET /api/state` ก๊วนและคนเข้าร่วมทั้งหมด
- `POST /api/games` ตั้งก๊วน
- `DELETE /api/games/:id` ลบก๊วน (เฉพาะคนตั้ง)
- `POST /api/games/:id/join` เข้าร่วม
- `DELETE /api/games/:id/join` ถอนตัว
